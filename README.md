# CapyWork Releases

This public repository is only used for CapyWork installer downloads and automatic update metadata.

It does not contain CapyWork source code.

## Downloads

Use the latest GitHub Release for macOS and Windows installers.

- macOS Apple Silicon: arm64 DMG
- macOS Intel: x64 DMG
- Windows: x64 EXE installer

## Updates

CapyWork checks this repository for new public releases when the app looks for updates.
